# Candidate trust signals (for discussing 'what is reliable?')

- Authority: approved by named owner, approval date present (policy) vs personal drive / no author
- Currency: effective date, superseded_by, draft status, review overdue
- Applicability: country, customer, contract override, joint committee
- Provenance: official repository vs chat vs AI-generated unreviewed summary
- Corroboration: independent sources agreeing (policy + email + ticket) vs +1 chains (NOT independent)
- Correction signals: retraction emails, replies correcting a chat message, reopened tickets
- Integrity: internal consistency, hidden instructions, spoofed sender domain, Reply-To mismatch
- Expertise: directory entry + recent activity + actual answers in channels
- Gaps: overdue reviews, 'nobody owns it', questions with only low-authority evidence
