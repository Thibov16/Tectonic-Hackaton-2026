# Payroll Input Deadlines (Belgium) - v4.0

1. Customers must submit monthly variable pay input (overtime, bonuses, absences) no later than the 18th calendar day of the month.
2. If the 18th falls on a weekend, the previous working day applies.
3. Late input is processed in the next pay run unless an Urgent Correction is approved by a Payroll Team Lead.
4. Customer contracts may define an earlier deadline; the contract deadline then applies.
